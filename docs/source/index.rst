=========================
ScySeqTools Documentation
=========================

Use the Encoder to label behaviour in recordings and the Analyser to explore
the resulting sequences. The :doc:`userguide` walks through a project from
the first recording to exported results.

To work on ScySeqTools itself, start with the :doc:`devel` for environment
setup, testing, and packaging. The :doc:`codedoc` describes the Python
modules behind both apps.
